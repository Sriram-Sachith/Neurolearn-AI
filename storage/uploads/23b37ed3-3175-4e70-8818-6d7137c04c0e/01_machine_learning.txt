Lecture notes — Introduction to Machine Learning
Page 1
Supervised learning is a machine learning approach that learns from labelled training data.
The goal is to map inputs to known outputs so that unseen examples can be predicted.
Classification assigns discrete class labels. Regression predicts continuous numeric targets.

Page 2
Unsupervised learning finds structure without labels. Clustering groups similar examples.
Dimensionality reduction compresses features while preserving variation.
K-means is a clustering algorithm that minimises within-cluster squared error.

Page 3
Model evaluation uses precision, recall and the F1 score.
Precision is the fraction of retrieved instances that are relevant.
Recall is the fraction of relevant instances that were retrieved.
Overfitting happens when a model memorises training examples instead of generalising.
