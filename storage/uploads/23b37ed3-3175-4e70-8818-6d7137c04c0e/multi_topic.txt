Machine Learning Fundamentals. Machine learning is a subfield of artificial intelligence that enables systems to learn patterns from data. Supervised learning uses labeled examples to train models that map inputs to outputs. Classification predicts discrete labels while regression predicts continuous values. A decision tree splits data using feature thresholds to maximise information gain. Overfitting occurs when a model memorises training noise and generalises poorly. Regularisation techniques like L1 and L2 penalise large weights to reduce overfitting. Cross-validation estimates generalisation by partitioning data into folds. Gradient descent updates parameters to reduce loss and the learning rate controls step size. Support vector machines find the maximum-margin hyperplane separating classes. Random forests average many decision trees trained on bootstrap samples. Neural networks stack layers of linear transformations followed by nonlinear activations. Backpropagation computes gradients via the chain rule to train deep networks. Machine Learning Fundamentals. Relational Database Concepts. A relational database organises data into tables of rows and columns. The primary key uniquely identifies each row in a table. A foreign key references a primary key in another table to enforce relationships. Normalisation reduces redundancy by splitting tables into smaller structures. Third normal form eliminates transitive dependencies between non-key attributes. An index accelerates queries by storing a sorted lookup structure on a column. A transaction is a unit of work that must satisfy ACID properties. Atomicity guarantees all operations in a transaction succeed or none do. Consistency ensures a transaction moves the database from one valid state to another. Isolation controls how concurrent transactions interact. Durability guarantees committed changes survive crashes. A join combines rows from two tables based on a related column. An inner join returns only matching rows while an outer join preserves unmatched rows.
